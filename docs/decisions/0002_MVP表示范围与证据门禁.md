# 决策 0002：MVP 表示范围与证据门禁

> 状态：MVP pilot 采用，formal 待冻结
> 日期：2026-07-26

## 决策

1. 同时评估 `image`、`text`、`fused` 三种冻结表示。
2. entity、predicate、direction 的条件增益主视图使用 image scope。
3. 严格 complementary 的 joint_graph 主视图使用 fused scope。
4. `image_only_matched` 采用无跨模态梯度的 batch 对半双单模态控制。
5. smoke/pilot 配置不能生成 formal 结果。
6. 自动裁决在全部阈值机器可读化前不能宣告 Go。

## 原因

严格协同信息若只在联合输入中可辨，就不能要求 image encoder 在没有文本时恢复独立 text key。将表示范围显式分开，可以避免把融合收益错误解释为目标模态表征收益。

## 后果

- 主结果必须标明 representation scope；
- delta 的 image-only baseline 与目标 scope 必须在聚合中显式记录；
- formal 前仍需确认任务到主 scope 的最终映射和交互统计模型。
