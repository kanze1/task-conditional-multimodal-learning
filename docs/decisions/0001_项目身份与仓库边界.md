# 决策 0001：项目身份与仓库边界

> 状态：已确认
> 日期：2026-07-26

## 决策

- 中文名：**多模态学习中的任务条件信息价值与结构表征**
- 英文名：**Task-Conditional Information Value in Multimodal Representation Learning**
- Git 仓库名：**`task-conditional-multimodal-learning`**
- GitHub：**`kanze1/task-conditional-multimodal-learning`**

## 研究定位

项目定位为“机制分析 + 可控诊断”，第一阶段不提出新 loss 或新 fusion architecture，不把 GCL 作为中心贡献。

## 仓库边界

本仓库是独立新仓库：

- 不继承 `kanze1/vlm-relational-snr` 的 Git 历史；
- 不把旧实验结果当作新项目证据；
- 旧仓库仅作为经验、失败记录和候选代码来源；
- 任何代码迁移都必须显式审查并以新数据契约、路径规范和测试重新验收。

## 原因

旧项目存在诊断—干预 regime 断裂、方法原创性不足、训练—评估几何同构、外部泛化不足和视觉 grounding 控制不足。新项目需要回到可证伪的条件规律，而不是延续旧方法包装。
