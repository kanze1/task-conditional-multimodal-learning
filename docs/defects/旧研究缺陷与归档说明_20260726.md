## 1. 最终产品状态

旧项目完成了：

- CLIP/OpenCLIP 的 entity / predicate / role 结构敏感性诊断；
- Visual Genome 派生的受控 probe；
- scratch CLIP-like 统一训练框架；
- InfoNCE、HardNeg、CF-InfoNCE、GCL 控制链；
- 多 seed、组合划分、尺度曲线、学习动态和梯度桥接；
- VALSE、Winoground 和 generator-shift 边界检查；
- NeurIPS 2026 完整论文稿。

NeurIPS 2026 审稿结果为两位 Borderline Reject、一位 Reject。Area Chair 的元评审确认了四类核心问题：

1. 诊断与干预不在同一模型 regime；
2. 理论假设和真实 InfoNCE 优化之间的连接不足；
3. GCL 相对既有 structured/counterfactual negative 方法的新颖性不足；
4. 外部比较、实现细节和视觉 grounding 控制不足。

## 2. 致命缺陷

### D1：诊断—干预断裂

层级现象主要在预训练 CLIP/OpenCLIP 上诊断；GCL 的强结果主要来自自建 scratch CLIP-like 模型。当前证据不能证明 GCL 修复了被诊断的真实预训练模型。

### D2：方法原创性不足

GCL 的实质是 anchor-aligned role/predicate/entity textual negatives，与 NegCLIP、SVLC、TripletCLIP 等已有路线高度接近。“graph-structured”没有对应新的图模型、图推理或独立算法结构。

### D3：训练—评估几何高度对齐

最强提升来自与训练负例同构的 Visual Genome 派生 probe。它证明 targeted training 有效，但不能充分证明通用关系理解。

### D4：外部泛化不足

- VALSE action 子集仅有小幅正增益；
- Winoground text/group 指标下降；
- matched generator shift 下 predicate accuracy 低于 InfoNCE；
- 自建 ARO-style 仍属于 Visual Genome 家族，不能视为独立外部 benchmark。

### D5：视觉 grounding 未被排除

结构反例全部位于文本侧。缺少 frozen-image、frozen-text、shuffled-image 和 text-only 控制，无法排除主要收益来自词序、模板或 lexical pattern 学习。

### D6：机制证据没有跨越到真实预训练分布

单负例 stylized theory 使用预设 exposure ordering；主 exposure 表未完整报告 entity confuser；真实多负例 softmax 权重与大型预训练数据中的 confuser 分布没有得到直接验证。

### D7：复现说明不完整

论文没有清楚、集中地说明自建 backbone、初始化、tokenizer、预处理、所有优化超参及 HardNeg/CF-InfoNCE 的精确定义。仓库代码包含绝对 Windows 路径，影响可移植性。

## 3. 已确认的边界事实

1. entity-sensitive discrimination 通常强于 predicate/role，但该现象已有相关 benchmark 报告，不能单独承担原创性。
2. GCL 在受控 VG 关系 probe 上有稳定、多 seed 的显著提升。
3. role/direction 收益比 predicate generator-shift 收益更稳。
4. GCL 改善 local structural near-miss，不等于改善 full-gallery retrieval。
5. 现有结果不支持“解决开放域 compositionality”。

## 4. 可迁移资产

- entity / predicate / role 分解；
- same-entity、directional/symmetric probe；
- counterfactual generator 与机械审计；
- 多 seed 和 matched-compute 实验纪律；
- generator shift 与外部边界报告方式；
- 失败结果及其 claim 收缩过程。

## 5. 不迁移的技术债

- 硬编码绝对路径；
- 旧主线中的 GCL 命名和 graph 包装；
- 只面向 Visual Genome 的数据契约；
- 旧结果 JSON 中不统一或可能被覆盖的通用字段；
- smoke、历史中间产物和正式结果混居；
- 从 scratch 小模型对真实预训练 VLM 的外推。

## 6. 新仓库迁移约束

新仓库只迁移研究问题、任务分解、审计纪律和已确认的失败边界：

- 不复制旧仓库 Git 历史；
- 不复制旧结果作为新项目证据；
- 不直接复制旧代码作为默认实现；
- 如需复用具体评估代码，必须逐文件审查路径、数据契约、字段命名和测试，并在新仓库中保留来源说明；
- GCL 仅可作为后续可选案例，不得出现在第一阶段默认方法矩阵中。

## 7. 最终决策

旧论文不再以当前主线直接改投 ICLR。新研究回到更初始的问题：

> 多模态训练的表征收益是否由任务条件信息价值决定？

旧项目只作为经验和失败证据来源，不作为新项目的默认代码基线。
