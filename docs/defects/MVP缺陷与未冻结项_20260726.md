# MVP 缺陷与未冻结项

> 状态：进行中
> 日期：2026-07-26
> 最近更新：MVP 代码搭建完成，但按用户要求尚未运行

## D-MVP-1：严格互补与 image-only 主指标存在逻辑边界

若 `joint_graph` 的一部分只存在于文本，冻结 image representation 不可能单独恢复该独立信息。当前实现将 joint_graph 的互补主检查放在 fused scope，并继续对 entity、predicate、direction 报告 image scope。

正式协议仍需确认这一主指标映射。不得把 fused 增益写成 image encoder 获得了不可见信息。

## D-MVP-2：架构与 seed 仅为 pilot 默认值

`tiny_vit`、`tiny_cnn` 和 `2601/2602/2603` 已进入配置，但尚未通过运行确认参数规模、稳定性与预算，也未冻结为 formal。

## D-MVP-3：零运行验证

根据用户要求，本次只搭建代码，没有执行：

- 依赖安装；
- ruff；
- pytest；
- 数据生成或审计；
- model forward；
- 训练、probe、聚合或裁决。

因此当前状态只能是“代码已搭建，等待运行验证”。

## D-MVP-4：48 GPU 小时可行性尚无实测

代码记录并限制累计 GPU/wall-clock 时间，但完整矩阵的吞吐和显存尚未实测。必须先跑 smoke，再决定 pilot epoch 或矩阵是否需要在协议冻结前调整。

## D-MVP-5：正式环境锁尚未生成

`pyproject.toml` 已声明依赖范围，但由于没有安装依赖，本次不能诚实生成 `uv.lock`。进入 formal 前必须由实际解析环境生成、审查并提交锁文件。

## D-MVP-6：自动 Go 判定故意不完整

当前裁决器能检查证据等级、协议状态、矩阵完整性、预算和部分 complementary 阈值，但 irrelevant 显著缩小、shuffled 控制和 conflict-flip 的最终统计定义尚未机器可读化。因此即使未来误用 formal 标签，也不会自动宣告 Go。

## D-MVP-7：自然数据外部验证未实现

这是第一阶段明确非目标。synthetic MVP 通过也不能直接支持预训练 VLM 或自然数据主张。
