# 新研究需求：多模态条件信息价值

> 状态：待协议冻结
> 日期：2026-07-26
> 权威计划：[`新研究计划_多模态条件信息价值_20260726.md`](../../新研究计划_多模态条件信息价值_20260726.md)
> 立项名称：多模态学习中的任务条件信息价值与结构表征
> 英文名称：Task-Conditional Information Value in Multimodal Representation Learning

## 1. 研究目标

建立一个可控实验框架，验证多模态训练相对单模态训练的表征收益是否由附加模态对目标任务的条件信息价值决定。

## 2. 必须回答的问题

1. 互补模态是否稳定提高冻结表示中的结构可解码性？
2. 冗余或无关模态是否只带来有限收益？
3. 冲突模态是否导致可预测的负迁移和鲁棒性下降？
4. 上述效应是否随实体、谓词、方向等结构任务而变化？
5. 受控实验得到的规律能否预测预训练 VLM 在自然数据中的表现？

## 3. 功能性研究需求

### 3.1 数据生成

- 从潜在场景图确定性生成视觉与文本投影；
- 支持 `redundant`、`complementary`、`irrelevant`、`conflict` 四种信息条件；
- 支持实体、谓词、方向和联合图属性标签；
- 每个生成版本必须有 manifest、seed 和不变量审计；
- 训练条件之间只允许改变预注册的信息变量。

### 3.2 训练

- 支持 `image_only`、`text_only`、`multimodal`、`shuffled` 和 `conflict`；
- 模型参数量、更新数、样本数和总 token 预算可审计；
- 支持至少两个轻量架构；
- 支持三 seed 最小验证和五 seed 正式验证；
- checkpoint 和日志必须携带完整配置哈希。

### 3.3 评估

- 冻结 encoder 的线性 probe；
- unseen-combination；
- missing/noisy/conflicting modality；
- 结构任务分项与交互效应；
- 自动生成 seed 统计、置信区间和失败样例。

## 4. 非功能需求

- 单张 RTX 4090 可完成 Go/No-Go；
- 第一阶段总预算不超过 48 GPU 小时；
- 数据生成和评估必须可在 CPU 上复核；
- 不允许硬编码绝对本地路径；
- 不允许把 smoke 结果写成正式证据；
- 所有主结论必须能映射到具体结果文件和运行配置。

## 5. 明确非目标

- 第一阶段不提出新 loss 或新 fusion architecture；
- 不训练大型 MLLM；
- 不以 Visual Genome 同源训练—测试结果作为外部泛化证据；
- 不直接估计高维神经表示的 PID 并将其当作真值；
- 不声称多模态普遍优于单模态；
- 不复用 GCL 作为默认主方法。

## 6. 阶段验收

Go/No-Go 完成必须同时具备：

1. 冻结实验协议；
2. 数据生成器审计；
3. 两架构、三 seed 主矩阵；
4. 公平预算核对；
5. 预注册阈值裁决；
6. 缺陷与失败记录。

缺少任一项，都只能标为“实验进行中”，不能进入论文写作。
