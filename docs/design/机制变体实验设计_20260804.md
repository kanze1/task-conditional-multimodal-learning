# 机制变体实验设计：互补 key 被对齐训练抹除的成因

> 日期：2026-08-04 ｜ 证据等级：pilot（诊断用途，不进入冻结矩阵，不参与 Go/No-Go）
> 前置发现：pilot 中 complementary joint_graph 的 fused 可解码性被 multimodal_aligned
> 训练压到远低于"单模态训练 + 随机文本塔拼接"基线（0.46/0.28 对 ≈1.0），见
> `docs/reports/pilot结果报告_20260804.md`。

## 一、竞争假说

- **H1（独立性）**：key 被抹除是因为它跨模态零相关，对 InfoNCE 配对目标零贡献，被表示
  学习当作噪声清除。
- **H2（显著性）**：key 被抹除只因感知显著性太低（图像 4×4/1024 像素、文本 1/14 token），
  编码器容量分配忽略了它，与训练目标无关。

## 二、2×2 因子设计

操纵两个数据生成轴（新配置字段，进入配置哈希，数据物理隔离）：

- `visual_key_salience`：`patch`（现状，4×4 角块）→ `background`（整幅背景亮度编码
  visual_key，约 1000 像素，同时保留角块，为默认渲染的信息超集）；
- `key_correlation` ρ：`0.5`（现状，跨模态独立）→ `0.9`（text_key 以 90% 概率等于
  visual_key，key 成为有效的跨模态配对线索；单模态天花板与边缘分布随 ρ 参数化进入
  oracle 审计）。

| 格子 | 显著性 | ρ | 数据集/配置 |
|---|---|---|---|
| 基线（已完成） | 低 | 0.5 | pilot 主矩阵 |
| A | **高** | 0.5 | `mvp_variant_salient.yaml` |
| B | 低 | **0.9** | `mvp_variant_correlated.yaml` |
| C | **高** | **0.9** | `mvp_variant_salient_correlated.yaml` |

每格：2 架构 × {image_only, multimodal_aligned} × complementary × 3 seed = 12 训练
run + 36 probe，输出根目录 `artifacts_v2_variants/<name>/`，与主矩阵物理隔离。

## 三、预注册预测（运行前写定）

主指标为**抹除指数** E = acc(image_only, fused) − acc(multimodal_aligned, fused)，
任务 joint_graph，clean accuracy，逐架构报告。基线格 E ≈ +0.54（cnn）/ +0.70（vit）。

| 格子 | H1（独立性）预测 | H2（显著性）预测 |
|---|---|---|
| A（高显著、独立） | **E 仍显著为正**（抹除与显著性无关） | **E ≈ 0**（显著后即保留） |
| B（低显著、相关） | **E 显著缩小甚至反号**（key 变为配对线索被保留） | **E 仍显著为正**（仍不起眼） |
| C（高显著、相关） | E ≈ 0 | E ≈ 0 |

判读规则：A 与 B 的结果向量决定归因——(A 抹除, B 保留) 支持 H1；(A 保留, B 抹除)
支持 H2；(A 抹除, B 抹除) 提示两者皆非充分、需检查容量或优化动力学；(A 保留, B 保留)
提示两因子皆充分，主张需写成合取。C 作为一致性检查。ρ=0.9 时 joint_graph 的
image_only fused 参考天花板约 0.95（4 类不均匀），E 需相对该格子自身的 image_only
基线计算，不与基线格直接比绝对值。

## 四、预算与状态

- 预计每格约 1.8 小时 wall-clock（生成 ~20 分 + 审计 ~4 分 + 训练 ~20 分 + probe
  ~64 分），三格合计约 5.5 小时；主矩阵已用 13.8 GPU 小时，预算充足。
- 变体运行是**机制诊断**：结果写入变体报告，用于决定冻结协议中主张的表述强度
  （"对比目标的原理性信息选择" vs "感知显著性局限"），不改变主矩阵任何产物。
- 阈值参数化（ρ 进入 oracle 天花板）已在 pilot 规模内存模拟与微型端到端审计验证。
